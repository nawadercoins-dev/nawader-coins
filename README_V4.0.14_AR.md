# نوادر العملات V4.0.14 — إصلاح قراءة الصور

- إصلاح السبب الذي كان يحوّل نتيجة OCR غير الناجحة إلى رسالة مضللة: «تعذر الاتصال بقاعدة البيانات المشتركة».
- خدمة تحليل الصور أصبحت مستقلة في الواجهة عن API الحفظ وقاعدة البيانات.
- عند عدم توفر Tesseract تظهر رسالة OCR الحقيقية، بينما يستمر رفع الصور وحفظ المقتنى بصورة طبيعية.
- تحليل الوجه والخلف يجمع النتائج المقترحة ويملأ الحقول الفارغة فقط.
- لا يتم اعتبار فشل OCR فشلاً في حفظ المقتنى.

## متطلب القراءة المحلية
تحتاج القراءة الآلية على ويندوز إلى Tesseract OCR مع العربية والإنجليزية، إضافة إلى Python packages: Pillow و pytesseract.
