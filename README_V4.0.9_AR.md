# نوادر العملات V4.0.9 — عارض صور المزادات الموحد

تم بناء هذا الإصدار مباشرة على V4.0.8 للحفاظ على إصلاح حفظ الأرقام المميزة.

## الترقية
- الضغط على صورة الوجه أو الخلف في المزاد يفتح عارضًا كبيرًا خارج البطاقة.
- تكبير وتصغير حتى 6×، تدوير يمين/يسار، توسيط، وإعادة 100%.
- سحب الصورة بعد التكبير ودعم التكبير بإصبعين على الشاشات اللمسية.
- التنقل بين جميع صور المقتنى داخل العارض.
- إغلاق العارض وإرجاع الصورة إلى وضعها الطبيعي.
- لا يتم إعادة تحميل المزاد أو إيقاف المؤقت عند فتح العارض.
- تم الإبقاء على إصلاح V4.0.8 الخاص بحفظ الأرقام المميزة دون إزالة.
