# نوادر العملات — V4.0.11

## إضافة مقتنى من حساب العميل للاعتماد

- بطاقة «إضافة مقتنى للاعتماد» داخل صفحة حسابي.
- إدخال الدولة والفئة والسنة والإصدار والحالة والرقم التسلسلي والوصف.
- رفع صورة الوجه والخلف مع ضغط محلي قبل الإرسال.
- اختيار رغبة العميل: مقتنياته فقط / السوق / المزاد بعد الاعتماد.
- حالة الطلب للعميل: قيد المراجعة، يحتاج استكمال، معتمد، مرفوض.
- صفحة إدارية مستقلة «اعتماد المقتنيات».
- إجراءات الإدارة: اعتماد وإضافة للسجل، طلب استكمال، رفض مع ملاحظة.
- الاعتماد لا ينشر تلقائيًا في السوق أو المزاد.
- إشعارات تلقائية للإدارة والعميل.
- طلبات اعتماد المقتنيات داخلة في النسخ الاحتياطي الكامل والاستعادة.
