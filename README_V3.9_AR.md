# نوادر العملات V3.9 — لوحة التحكم والتصميم الموحد

هذا الإصدار يضيف لوحة تحكم إدارية رئيسية فعلية، ويجعلها الصفحة الأولى بعد دخول الإدارة.

أهم التغييرات:
- لوحة مؤشرات للمقتنيات والمخزون والمزادات والطلبات والاعتمادات.
- اختصارات مباشرة للمقتنيات، المزادات النشطة، المزادات المنتهية، السوق، المشاركين، المالية والنسخ الاحتياطي.
- إبراز المزادات المنتهية كقسم إداري مستقل مع الوصول المباشر لإعادة الإدراج.
- توحيد هوية الإدارة بالكحلي والذهبي وتحسين البطاقات والمسافات والمحاذاة.
- تحسين استجابة لوحة التحكم للجوال والكمبيوتر.
- الحفاظ على وظائف V3.8 بما فيها سجل جولات المزادات وإعادة الإدراج.

النسخة V3.8 تبقى نسخة رجوع مرجعية ولا يلزم استبدالها إلا بعد اختبار V3.9 داخليًا.
