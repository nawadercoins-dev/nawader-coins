نوادر العملات — V4.0.21 RECORD CLASSIFICATION

تمت الترقية انطلاقًا من V4.0.20 ADMIN UI CLEANUP مع المحافظة على منطق المزاد والسوق والبيانات.

التعديلات:
1) نقل بيانات المالك/البائع إلى أعلى نموذج إضافة/تعديل المقتنى.
2) إعادة تنظيم إدخال الأرقام التسلسلية: عند زيادة الكمية تظهر داخل مجموعة قابلة للفتح/الإغلاق بدل تمديد الصفحة بشكل مزعج.
3) إضافة تصنيف سجل المقتنيات: الكل / المقيمة / غير المقيمة / الأطقم، مع عدادات.
4) إضافة تصنيف فرعي للأطقم حسب عدد القطع: ميني 2–3، صغيرة 4–5، متوسطة 6–10، كبيرة أكثر من 10.
5) تطبيق نفس منطق التصنيف على صفحة السوق العام الإدارية.
6) تحسين تنظيم قسم موقع التخزين وشرح مساره الموحد.
7) تحسين المسافات والقراءة داخل بطاقات السجل.
8) لا تغيير في منطق المزاد أو البيع أو الحفظ أو بنية البيانات الحالية.
