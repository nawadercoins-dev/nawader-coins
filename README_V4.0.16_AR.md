# نوادر العملات V4.0.16 — تحليل OCR للعملات ودرجات الثقة

هذه الترقية مبنية مباشرة على V4.0.15 وتحافظ على اكتشاف Tesseract ومساره كما هو، بدون إعادة تثبيت أو تغيير المحرك.

## ما الجديد
- تحويل النص المقروء من OCR إلى حقول عملة أكثر دقة: الدولة، الفئة/القيمة، السنة، والرقم التسلسلي.
- دعم الأرقام العربية والهندية وتحويلها لصيغة موحدة أثناء التحليل.
- دعم الفئات المكتوبة بالكلمات مثل «عشرة دراهم» و«خمسة ريالات».
- درجات ثقة لكل معلومة: عالية / اقتراح للمراجعة / منخفضة.
- البيانات عالية الثقة تملأ الحقول الفارغة فقط ولا تستبدل إدخال المستخدم.
- البيانات متوسطة الثقة تظهر في لوحة اقتراحات مع زر «اعتماد الاقتراح».
- البيانات منخفضة الثقة لا تُملأ تلقائيًا.
- إمكانية عرض النص الخام الذي قرأه OCR للمراجعة.
- بقاء رفع الصور وحفظ المقتنى مستقلين عن OCR بالكامل.

## قاعدة الاعتماد
Tesseract في V4.0.15 ثبت أنه يعمل؛ لذلك V4.0.16 لا تعيد تثبيته ولا تغيّر مساره، وإنما تطوّر طبقة OCR → تحليل العملة → تعبئة الحقول.
