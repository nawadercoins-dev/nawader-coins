# نوادر العملات — V4.0.12

## ترقية تحليل صور المقتنى
- تغيير الزر إلى «تحليل صور المقتنى».
- تحليل صورة الوجه والخلف عند توفرهما بدل الاعتماد على الوجه فقط.
- دمج البيانات المستخرجة وملء الحقول الفارغة فقط حتى لا تُستبدل بيانات المستخدم.
- الرقم التسلسلي يمر إلى محلل الأرقام المميزة بعد استخراجه.
- فشل OCR لا يمنع رفع الصور أو حفظ المقتنى.
- رسالة واضحة بعدد البيانات المقترحة المستخرجة.
- تحسين التعرف على صيغ أسماء الفئات العربية.

ملاحظة تشغيلية: القراءة المحلية تعتمد على Tesseract OCR عند توفره على جهاز ويندوز، ويفضل تثبيت حزمتي العربية والإنجليزية.
