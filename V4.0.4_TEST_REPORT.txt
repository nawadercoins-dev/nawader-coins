# نوادر العملات V4.0.4 — QUALITY REVIEW

تم البناء على V4.0.3 QUALITY CYCLE بعد مراجعة الملاحظات الأخيرة.

## التصحيحات
- تشغيل تسوية نتيجة المزاد تلقائيًا عند انتهاء المزاد الناجح عند تحديث البيانات العامة/الإدارية، لإنشاء استحقاق الفائز وطلبه وإشعاراته مرة واحدة فقط.
- بقاء المزاد المنتهي الناجح في صفحة المزادات المنتهية مع حالة البيع/الفائز.
- دعم أكثر من تصنيف للرقم التسلسلي: متكرر، متسلسل، متطابق، نادر/مميز، وربطه بنفس سجل المقتنى.
- صفحة الأرقام المميزة تستقبل التصنيفات المتعددة دون تكرار سجل المقتنى.
- تصغير وضبط صور المقتنيات داخل بطاقات الطلبات والشحن مع بقاء التكبير عبر عارض الصور.
- تحسين أحجام خطوط مركز الإشعارات.

## فحوصات البناء
- Python server.py: py_compile ناجح.
- JavaScript admin/app.js: node --check ناجح.
- تم الحفاظ على التوافق مع الحقل القديم specialNumberType وإضافة specialNumberTypes.
