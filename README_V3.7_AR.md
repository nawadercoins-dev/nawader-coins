# نوادر العملات V3.7 — STRUCTURE & SECURITY

هذه النسخة مشتقة من V3.6 مع الحفاظ على V3.6 كمرجع منفصل دون تعديل.

## ما تم في V3.7
- فصل واجهة الإدارة فعليًا داخل مجلد `admin/`.
- فصل واجهات الزوار والعملاء داخل مجلد `public/`.
- نقل الأصول المشتركة إلى `shared/`.
- حماية `/admin` وملفات JavaScript/CSS الإدارية بجلسة الإدارة.
- إبقاء `/home` و`/market` و`/auction` وواجهات الزوار عامة فقط.
- إضافة ترويسات أمان HTTP أساسية: nosniff، منع الإطارات، Referrer-Policy، Permissions-Policy، CSP أساسي.
- تحديث رقم الإصدار إلى `3.7.0-STRUCTURE-SECURITY`.
- عدم تضمين كلمة مرور إدارة جاهزة في الحزمة؛ تُنشأ بيانات دخول جديدة عند أول تشغيل.
- نقل وثائق الإصدارات السابقة إلى `documentation/archive/` بدل خلطها مع ملفات التشغيل.

## المسارات
- الإدارة: `/admin`
- دخول الإدارة: `/admin-login`
- واجهة الزائر: `/home`
- المزاد العام: `/auction`
- السوق العام: `/market`

## ملاحظة مهمة
هذه ما زالت نسخة تطوير محلية، وليست جاهزة للنشر العام على الإنترنت قبل استكمال قاعدة البيانات، جلسات العملاء، OTP الحقيقي، وحماية الإنتاج.
