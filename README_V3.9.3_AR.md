# نوادر العملات V3.9.3 — SAFE UI UPGRADE

مبني مباشرة على V3.9.2 المستقرة.

## التعديلات
- الإبقاء على منطق النسخ الاحتياطي والاستعادة كما هو.
- استبدال حالة السوق «منشور» بـ «نشط» باللون الأخضر، و«غير نشط» باللون الأحمر.
- جعل نوع العرض وحالة النشاط في سطر واحد متباعد ومنظم.
- زيادة المسافات بين بطاقات لوحة التحكم.
- تفعيل صفحة «الإعدادات وبيانات الدخول» للإعدادات المالية الأساسية وبيانات المنصة المحلية.
- QR المزاد والسوق يبقيان ثابتين كما في النسخة المستقرة.

## مؤجل عمدًا للإصدارات التالية
الصلاحيات التفصيلية، مركز الإشعارات، الأرشيف والحذف النهائي، تقارير الفترات، وسجل العمليات؛ حتى تُنفذ كل وحدة وتُختبر دون المساس بالنسخ الاحتياطي المستقر.
