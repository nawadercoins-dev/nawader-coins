# نوادر العملات V4.0.13 — اعتماد مقتنيات العملاء

## الجديد
- بطاقة «إضافة مقتنى للاعتماد» داخل حساب العميل.
- نموذج بيانات المقتنى وصور الوجه والخلف والرقم التسلسلي والحالة.
- اختيار رغبة العميل بعد الاعتماد: المقتنيات / السوق / المزاد، دون نشر تلقائي.
- إرسال الطلب إلى الإدارة بحالة قيد المراجعة.
- صفحة إدارية مستقلة «اعتماد المقتنيات» مع عدادات وصور ومعاينة مكبرة.
- إجراءات الإدارة: اعتماد وإضافة للسجل، طلب استكمال، رفض.
- إشعارات للعميل والإدارة مع الاحتفاظ بسجل العملية.
- عرض حالة الطلب داخل حساب العميل: قيد المراجعة / يحتاج استكمال / معتمد / مرفوض.
- استمرار فصل الاعتماد عن النشر: الاعتماد لا ينشر تلقائياً في السوق أو المزاد.

## ملاحظة
هذه الترقية مبنية على V4.0.12 وتحافظ على ترقية تحليل الصور السابقة.
