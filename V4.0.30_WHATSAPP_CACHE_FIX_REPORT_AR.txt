نوادر العملات — تقرير إصلاح V4.0.30
WHATSAPP FRONTEND CACHE RESET

سبب المشكلة:
كان الخادم الجديد يعمل بنظام واتساب، بينما المتصفح أو نسخة PWA القديمة تعرض صفحة رمز SMS المخزنة. نتج عن خلط النسختين الخطأ:
Cannot read properties of undefined (reading 'id')

الإصلاح:
1. حذف جميع ذاكرات Cache API القديمة تلقائيًا.
2. إلغاء تسجيل أي Service Worker قديم يمنع تحديث صفحات العملاء.
3. تزويد صفحة الحساب والمزاد برؤوس تمنع التخزين وتطلب مسح ذاكرة الواجهة.
4. تحديث جميع روابط CSS وJavaScript إلى الإصدار 4.0.30.
5. إضافة علامة ظاهرة في صفحة الحساب: «نظام واتساب المجاني — الإصدار V4.0.30».
6. منع عودة صفحة إدخال رمز SMS القديمة.

اختبار الدورة الكاملة:
PASS: إنشاء طلب توثيق واتساب.
PASS: إنشاء رابط إلى الرقم 966551892409 متضمنًا رمز الطلب.
PASS: بقاء العميل معلقًا قبل اعتماد الإدارة.
PASS: اعتماد الإدارة للطلب.
PASS: منح الدخول للعميل بعد الاعتماد فقط.
PASS: عدم وجود «أدخل الرمز» أو «إرسال رمز التحقق» في صفحة الحساب.
PASS: حذف ذاكرة PWA القديمة وإلغاء عامل الخدمة القديم.
