# نوادر العملات V4.0.3 — QUALITY CYCLE

ترقية مبنية مباشرة على V4.0.2 بعد مراجعة الملاحظات التشغيلية والبصرية.

## أهم ما تم تنفيذه
- إصلاح دورة المزاد الناجح: إنشاء مستحق + طلب + إشعار للفائز، حتى للحالات الناجحة التي سبقت تفعيل تتبع المستحقات، مع مهلة جديدة 24 ساعة للحالات المصالَحة حتى لا يحدث حظر بأثر رجعي.
- تثبيت نتيجة المزاد على سجل المقتنى وربطها برقم الطلب.
- إظهار المزاد الناجح في «المزادات المنتهية» باللون الأخضر «تم البيع / فائز»، وغير الناجح «انتهى دون بيع».
- إصلاح خلل parse_qs الذي كان يمنع بعض مسارات الإشعارات/الحساب من العمل.
- تنظيم سجل المقتنيات: الفئة دون تكرار الدولة، الكمية والمباع والمتبقي عموديًا، وحالة السوق والمزاد في قسم موحد.
- زر «لوحة الإدارة» داخل شريط واجهات الزائر عند وجود جلسة إدارة، مع إبقاء الزر العائم.
- تقليل ارتفاع بطاقة المزاد العامة وإنهاء تمدد المنطقة السوداء الفارغة أسفل صور العملة.
- إضافة «الأرقام المميزة» داخل نموذج إضافة المقتنى: متكرر/متسلسل/متطابق/نادر + سبب التميز، وعرضها ديناميكيًا في صفحة الأرقام المميزة.
- لم يتم تغيير دوال إنشاء النسخة الاحتياطية أو الاستعادة؛ تم التحقق من تطابقهما حرفيًا مع V4.0.2.

## قاعدة الاعتماد
المراجعة -> التنفيذ -> الاختبار -> إعادة المراجعة -> الاعتماد.
