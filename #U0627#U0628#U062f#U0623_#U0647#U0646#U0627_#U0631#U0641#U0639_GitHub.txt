نسخة GitHub النظيفة — نوادر العملات V4.2.2

سبب الرسالة السابقة:
فتح الملف المضغوط ثم سحب محتوياته يجعل WinRAR ينقل الملفات عبر مجلد مؤقت
اسمه Rar$... وقد يبدأ النقل ثم يصطدم بأسماء موجودة أو قديمة. ينتج عن ذلك رفع
جزء جديد مع جزء قديم، وهو ما حدث عندما وصل server.py الجديد وبقيت واجهة
الإدارة القديمة بلا مستودع.

الطريقة الصحيحة لفك الضغط:
1. لا تفتح الملف المضغوط ولا تسحب الملفات منه.
2. اضغط بزر الفأرة الأيمن على الملف المضغوط.
3. اختر «استخراج الكل...» أو Extract All.
4. اكتب اسم وجهة جديدًا تمامًا مثل: NAWADER_V422_GITHUB_NEW
5. انتظر حتى ينتهي الاستخراج مرة واحدة.
6. افتح المجلد الجديد. يجب أن ترى مباشرة:
   server.py
   requirements.txt
   admin
   public
   shared
7. لا تنقل هذه الملفات إلى مجلد إصدار قديم.

طريقة رفعها إلى GitHub:
1. افتح مستودع nawader-coins في GitHub.
2. اختر Add file ثم Upload files.
3. افتح المجلد NAWADER_V422_GITHUB_NEW على الكمبيوتر.
4. حدد المحتويات الموجودة داخله، ولا ترفع المجلد الخارجي نفسه.
5. اسحب server.py والمجلدات admin وpublic وshared وبقية الملفات إلى صفحة الرفع.
6. انتظر حتى تظهر الملفات في قائمة GitHub.
7. اضغط Commit changes مرة واحدة.
8. افتح admin/index.html في GitHub وتأكد أن العنوان يحتوي V4.2.2 وأن النص
   data-v="warehouse" موجود.
9. افتح Render ثم Manual Deploy ثم Deploy latest commit.
10. بعد اكتمال النشر افتح الموقع في نافذة خاصة، أو اضغط Ctrl+F5.

علامات نجاح الترقية:
- /api/version يعرض 4.2.2.
- عنوان صفحة الإدارة يعرض V4.2.2 وليس V4.0.24.
- زر «المستودع» ظاهر في شريط الإدارة.
- داخل المستودع يظهر زر «فحص وإصلاح المقتنيات المعتمدة سابقًا».

تنبيه:
لا تختَر «استبدال» ولا «تخطي» في نافذة Windows؛ إذا ظهرت النافذة فهذا يعني
أن الاستخراج لم يتم بالطريقة الصحيحة أو أن الوجهة لم تعد فارغة. ألغِ العملية
وابدأ مرة واحدة بخيار «استخراج الكل» إلى اسم جديد تمامًا.
