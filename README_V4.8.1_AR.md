# نوادر العملات V4.8.1 — STABILITY

هذه الحزمة مرحلة استقرار فقط. لم يتم تنظيف CSS أو نقل الملفات التاريخية في هذه النسخة؛ ذلك مؤجل إلى V4.9.0 بعد نجاح التشغيل.

## ما تم إصلاحه

- إضافة جلسة عميل آمنة HttpOnly مرتبطة بالحساب.
- إضافة رمز دخول PIN للعملاء مع hash PBKDF2 وعدم الاعتماد على participantId وحده.
- منع أي حساب من تعديل مقتنيات حساب آخر.
- ترحيل آمن للحسابات القديمة: الجهاز الذي يحتفظ بمعرف الحساب القديم يمكنه تعيين PIN مرة واحدة؛ الأجهزة الجديدة تحتاج إعادة ضبط PIN من الإدارة.
- إلغاء مسار OTP القديم غير المستخدم.
- إلغاء اعتماد المقتنيات المسبق وتحويل لوحة الإدارة إلى «مراقبة المقتنيات».
- حالات الرقابة: active / hidden / suspended / archived / removed، مع سبب إلزامي للإجراءات المقيدة.
- إظهار هوية صاحب المقتنى والعلم في السوق والمزاد والأرقام المميزة والحالات الانتقالية.
- جعل الحالات الانتقالية تظهر كقسم مستقل حتى لو كان المقتنى للعرض/التوثيق فقط.
- إصلاح id المكرر warehouse في لوحة الإدارة.
- إضافة شاشة «سلامة المنصة» بفحص غير تدميري للتكرارات والروابط والمزادات والعروض.
- توحيد الإصدار إلى 4.8.1-STABILITY.
- إزالة ملف كلمة مرور الإدارة النصي من الحزمة.
- إلغاء كلمة مرور الإدارة الافتراضية المضمنة؛ ADMIN_PASSWORD في Render هو مصدر الإنشاء/التدوير.
- تصحيح مقارنة وقت المزاد مع توقيت السعودية.
- استمرار النشر المباشر للمقتنيات والسوق والمزاد والمميزة/النادرة والحالات الانتقالية.

## مهم قبل النشر

1. في Render عيّن متغير البيئة `ADMIN_PASSWORD` إلى كلمة مرور إدارة قوية جديدة.
2. لا ترفع أي ملف JSON من هذه الحزمة فوق بيانات `/var/data` الحية. الحزمة لا تحتوي ملفات البيانات أصلًا.
3. استبدل ملفات الكود بنفس المسارات فقط.
4. نفّذ Deploy ثم Ctrl+F5.

## الحسابات القديمة

بعد الترقية سيطلب النظام PIN.
- إذا كان العميل يستخدم نفس المتصفح الذي كان حسابه محفوظًا فيه، يمكنه إدخال الجوال واختيار PIN جديد؛ معرف الحساب القديم المحفوظ يستخدم لترحيل الحساب بأمان.
- إذا كان على جهاز جديد، تفتح الإدارة: المشاركون ← «رمز الدخول» وتعين له PIN جديد.
- تغيير PIN من الإدارة ينهي الجلسات القديمة للحساب.

## اختبارات Regression المنفذة

- النشر المباشر للسوق + هوية البائع والعلم.
- النشر المباشر للمزاد + هوية البائع والعلم.
- الأرقام المميزة + هوية البائع والعلم.
- الحالة الانتقالية المستقلة.
- منع السوق بسعر صفر.
- منع موعد مزاد منتهٍ وفق توقيت السعودية.
- منع تعديل مقتنى حساب آخر.
- إخفاء المقتنى رقابيًا من الأقسام العامة.
- شاشة سلامة المنصة.
- تعطيل مسار التحقق القديم.
- إعادة ضبط PIN وإبطال الجلسة القديمة.
- البيع التلقائي للمزاد عند تحقق حد البيع وانتهاء الوقت.
- تعديل المزاد قبل المزايدات.
- قفل سعر الافتتاح بعد أول مزايدة.
- إلزام سبب الإلغاء عند وجود مزايدات.
- ترحيل حساب قديم إلى PIN من الجهاز القديم فقط.

## ما لم نفعله عمدًا

- لم نحذف أو ندمج حسابات مكررة تلقائيًا.
- لم نحذف الرقم التسلسلي المتعارض تلقائيًا.
- لم ننظف 1300+ !important أو CSS التاريخي.
- لم نحذف ملفات تقارير/إصدارات قديمة من المصدر.
