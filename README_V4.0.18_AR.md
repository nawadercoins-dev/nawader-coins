# نوادر العملات V4.0.18

ترقية تجميعية مبنية على V4.0.17.

- استكمال عارض الصور الموحد وإضافة ملء الشاشة للمزاد والإدارة.
- إضافة البحث في مزادات الزائر.
- إضافة مزادات قاربت على الانتهاء (آخر 6 ساعات) مع فلتر سريع.
- تثبيت التحسينات الموجودة في V4.0.17: الأرقام المميزة والتجارة والسلة واختيار التسلسلات، الصلاحيات البصرية، المستحقات بثلاثة إجراءات، شريط صافي أرباح المنصة، صور الطلبات المصغرة، طلبات اعتماد مقتنيات العملاء، وOCR.
- الحفاظ على البيانات والصور والسجلات دون حذف.
