نوادر العملات — V4.2.6
====================

التعديل:
- أصبح قسم «موقع التخزين» كاملًا مطويًا ومخفيًا افتراضيًا.
- عند الضغط على «موقع التخزين» تظهر القوائم المنسدلة: المستودع، الخزانة، الرف، الصندوق، الألبوم، الصفحة/الجيب.
- إغلاق القسم لا يحذف أي قيمة تم اختيارها.
- عند تعديل مقتنى قديم لديه موقع تخزين محفوظ، يفتح القسم تلقائيًا لإظهار موقعه.
- لم يتم تعديل server.py أو ملفات JSON أو بيانات المقتنيات والمزادات والعملاء.

طريقة الرفع:
ارفع app.js و index.html و styles.css فقط داخل مجلد admin في GitHub واستبدل الملفات الحالية.
