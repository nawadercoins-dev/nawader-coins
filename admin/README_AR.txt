نوادر العملات — V4.2.5 قوائم موقع التخزين
==========================================

التعديل يخص واجهة الإدارة فقط، ولا يغير server.py أو ملفات JSON أو منطق الحفظ.

ما تم تنفيذه:
- المستودع، الخزانة، الرف، الصندوق، الألبوم، الصفحة/الجيب أصبحت قوائم منسدلة.
- القوائم مترابطة وتعتمد على مواقع التخزين المسجلة فعليًا في المقتنيات الحالية.
- يوجد خيار «＋ إضافة جديد...» داخل كل قائمة لإدخال موقع جديد عند الحاجة.
- عند تعديل مقتنى قديم تظهر قيم موقعه الحالية حتى لو لم تكن ضمن القوائم السابقة.
- نفس أسماء الحقول القديمة محفوظة: warehouse/cabinet/shelf/box/album/pocket، لذلك لا يتغير منطق الحفظ أو البيانات.

طريقة الرفع:
1) ادخل GitHub إلى مجلد admin نفسه.
2) Add file > Upload files.
3) ارفع فقط: app.js و index.html و styles.css.
4) Commit changes.
5) لا ترفع README_AR.txt إلى admin (اختياري للاحتفاظ به على جهازك فقط).
6) انتظر نشر Render ثم Ctrl+F5.

اختبار سريع:
- إضافة مقتنى > موقع التخزين.
- اختر المستودع ثم الخزانة ثم الرف.
- جرّب «＋ إضافة جديد...» في أي مستوى.
- احفظ مقتنى تجريبيًا، ثم افتحه للتعديل وتأكد أن الموقع بقي كما هو.
