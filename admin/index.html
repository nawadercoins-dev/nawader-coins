النسخ الاحتياطي

النسخة الكاملة هي النسخة المعتمدة للنقل والاستعادة. تشمل البيانات والصور والمشاركين والمزايدات والتفاوض والإعدادات.

ملف JSON القديم يحفظ السجلات فقط ولا يُعتمد لنقل الصور.

⚠ استثناء مزاد ناجح

يستخدم فقط قبل اكتمال البيع. سيُلغى حجز الفائز والطلب غير المسدد مع حفظ السبب في سجل المزاد.

⚙️ تعديل المزاد النشط

تصحيح سريع لإعدادات الجولة الحالية دون حذف المزاد أو إنشاء جولة جديدة. تحفظ التعديلات في سجل العمليات.

♻️ إعادة طرح المقتنى في المزاد
