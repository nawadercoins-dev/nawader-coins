# نوادر العملات V4.0.8 — إصلاح موثوق لحفظ الأرقام المميزة

هذا الإصدار يعالج تحديدًا حالة ظهور رسالة `Failed to fetch` عند حفظ مقتنى بعد تصنيفه ضمن الأرقام المميزة أو الأخطاء النادرة.

## التعديل الجذري
- أصبح رد الخادم نفسه هو مرجع التحقق من نجاح الحفظ؛ لأنه يقوم بالكتابة ثم يعيد قراءة السجل ويتحقق منه قبل الرد.
- أزيل طلب الشبكة الإضافي الذي كان يحدث مباشرة بعد الحفظ ويستطيع إظهار رسالة فشل رغم نجاح الحفظ على القرص.
- أضيف تحقق مباشر من أن جميع تصنيفات الأرقام المميزة المختارة قد حُفظت فعلًا.
- أضيفت ثلاث محاولات اتصال تلقائية للحفظ وقراءة السجلات عند حدوث انقطاع لحظي في localhost.
- أصبحت رسالة تعطل الخادم أو إغلاق نافذة التشغيل أوضح للمستخدم بدل الاكتفاء بعبارة Failed to fetch.

لم يتم تغيير منطق النسخ الاحتياطي أو المزادات أو السوق أو الصور في هذه الترقية.
