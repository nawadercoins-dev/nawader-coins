# نوادر العملات V4.0.1 — الطلبات والشحن

هذه الترقية مبنية مباشرة على V3.9.6 FORM UI POLISH وتحافظ على ملفات البيانات السابقة وتضيف دورة تشغيل موحدة.

## المنفذ
- صفحة إدارية مستقلة: الطلبات والشحن.
- مصدر الطلب واضح: السوق العام أو المزاد.
- دورة الحالات: طلب جديد، بانتظار السداد، تم السداد، قيد التجهيز، جاهز للشحن، تم الشحن، تم الاستلام، مكتمل.
- حالات استثنائية: متعثر، ملغي، مرتجع.
- اكتمال الطلب يؤدي إلى الأرشفة ولا يحذف الطلب.
- بيانات العميل، العملات، الصور، الكمية، الأسعار والإجمالي، السداد، شركة الشحن، رقم التتبع، وموقع التخزين التفصيلي.
- طباعة ملخص/فاتورة.
- فوز المزاد ينشئ مستحقًا وطلبًا موحدًا ويرسل تهنئة وإشعار إنشاء الطلب.
- سداد الطلب الخاص بالمزاد يحدّث المستحق ويعيد أهلية المشاركة وفق النظام.
- منع مزايدة جديدة تلقائيًا عند وجود مستحق غير مسدد تجاوز 24 ساعة.
- قبول طلب السوق ينشئ طلبًا موحدًا في الطلبات والشحن.
- عارض صور احترافي في الإدارة والمزاد: تكبير/تصغير/تحريك/100%/تنقل ودعم اللمس.
- إعادة تنسيق بطاقات المقتنيات إلى شرائط واضحة.
- تحسين صفحة الصلاحيات وإضافة صلاحيات الطلبات.
- توحيد أحجام حقول تسجيل العملاء والمشاركين.
- زر العودة إلى الإدارة يظهر فقط عند وجود جلسة إدارة فعالة، ولا يظهر للزائر.
- orders_shipping.json مضاف إلى النسخة الاحتياطية الكاملة.

## اختبار تشغيلي تم قبل التسليم
تم اختبار: طلب سوق -> قبول -> إنشاء طلب -> السداد -> التجهيز -> جاهز للشحن -> الشحن -> الاستلام -> مكتمل -> أرشيف.
وتم اختبار: فوز مزاد -> إنشاء مستحق + طلب -> جعل المستحق متأخرًا لأغراض الاختبار -> رفض مزايدة جديدة برسالة واضحة.
تم حذف بيانات الاختبار من الحزمة قبل التسليم.
