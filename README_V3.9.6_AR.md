# نوادر العملات V3.9.6 — FORM UI POLISH

ترقية واجهات تسجيل العملاء والبائعين والزوار في صفحة المزادات وصفحة الحساب.

## ما تم
- توحيد نموذج الاسم ورقم الجوال وزر إرسال رمز التحقق.
- منع الحقول الطويلة والرفيعة غير المتناسقة.
- إضافة عناوين واضحة فوق الحقول.
- توحيد ارتفاع الحقول والأزرار والمسافات بينها.
- تحسين عرض رمز التحقق OTP.
- تصميم متجاوب للجوال والكمبيوتر.

## حماية الاستقرار
لم يتم تعديل server.py أو admin/app.js، وبالتالي لم يتم المساس بمنطق النسخ الاحتياطي والاستعادة أو منطق الإدارة المستقر في V3.9.5.
